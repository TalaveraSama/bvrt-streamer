Alcance real de esta auditoría. El payload ms_install_5.2.8.tar.gz no pudo descargarse: valut.iptvtools.io resuelve a BunnyCDN (169.150.249.163) pero la conexión TLS se corta, y el entorno solo tiene salida a GitHub/npm/PyPI. Por eso lo auditado es el instalador, que sí es público y Verificable, más el escáner para el payload en cuanto lo tengas. No afirmo nada sobre el PHP del panel que no haya podido leer.

1 · Veredicto

El instalador no es un troyano evidente: no descarga binarios ocultos, no contiene curl | bash, no tiene ofuscación. Pero deja el servidor en un estado que equivale a comprometido en cuanto alguien alcanza el puerto 7999 o consigue una ejecución de PHP: regala root sin contraseña, publica las mismas credenciales para todos los clientes del producto, y desactiva las dos capas de auditoría del sistema (SELinux y los logs de cron/sudo).

La combinación H-04 + H-11 + H-12 es la que más preocupa: credenciales conocidas de administrador, escalada a root sin contraseña y borrado de los logs que permitirían ver la escalada. Cada una por separado es un error de configuración; juntas son un patrón.

2 · Críticos

H-03 · MariaDB accesible desde cualquier host, con SUPER

ms_install_offline.sh:453-462
-- password idéntica en todas las instalaciones del mundo:
GRANT ALL PRIVILEGES ON midnight_iptv.* TO 'midnightstreamer'@'%' IDENTIFIED BY 'pglauD4F0L';
GRANT SUPER ON *.*                      TO 'midnightstreamer'@'%' IDENTIFIED BY 'pglauD4F0L';

Quien alcance el puerto 7999 entra como superusuario, lee y escribe cualquier base y puede usar SELECT … INTO OUTFILE para escribir archivos como el usuario mysql.

Parche: HARDENING 14 bind loopback, usuario solo @localhost, sin SUPER, password aleatoria.

H-04 · Administrador y claves del panel hardcodeados

ms_install_offline.sh:451-452 · 524
VALUES ('admin', '2cd71063c6a79832cdfeb889f4c072e425067fe2', …);
UPDATE settings SET preview_pass='hn6SImdyx7',
  stalker_key='02230129b6ad71bae0292032450090cd', api_key='dtqVa5xwoU';

El script termina imprimiendo «Username: admin / Password: iptv». Las claves stalker_key y api_key públicas permiten emitir peticiones firmadas contra cualquier panel que no las haya cambiado.

Parche: HARDENING 15 password + claves aleatorias, en /root/.midnightstreamer.credentials a 0600.

H-11 · NOPASSWD:ALL para el usuario del panel

ms_install_offline.sh:335-337
echo "midnightstreamer ALL = (ALL) NOPASSWD:ALL" >> /etc/sudoers

Cualquier RCE en el PHP del panel pasa a root sin contraseña. Es la diferencia entre «me tumbaron el panel» y «me tomaron el servidor».

Parche: HARDENING 16 no se toca /etc/sudoers y se elimina la regla si ya existe.

H-06 · Repos APT sin firma, EOL, por HTTP

ms_install_offline.sh:216-232
echo "deb [trusted=yes] http://httpredir.debian.org/debian jessie …" > …/midnightstreamer.list
echo "deb [trusted=yes] http://de.archive.ubuntu.com/ubuntu/ trusty …" >> …

[trusted=yes] desactiva la verificación GPG: lo que responda a esa URL se instala como root. Jessie y Trusty llevan sin soporte desde 2020 y 2019. Todo por HTTP claro. Y el archivo nunca se borra, así que sigue activo para los apt-get install futuros.

Parche: HARDENING 6 se elimina el archivo y se usan los repos del sistema.

H-07 · SELinux desactivado de forma permanente

ms_install_offline.sh:124-125
setenforce 0
sed -i 's/enforcing/disabled/g' /etc/selinux/config

Ninguna razón funcional lo justifica: si hubiera conflicto de contextos, se resuelve con semanage/restorecon. Aquí se apaga la única contención del sistema.

Parche: HARDENING 5 no se desactiva; relabel opcional con MS_SELINUX_RELABEL=1.

Cómo usarlo. MS_PAYLOAD_SHA256=<hash> sudo ./installer/ms_install_offline.sh para instalar; ./tools/scan_payload.sh <dir-extraido> para auditar el payload antes de instalar. El escáner devuelve exit 1 si encuentra algo crítico, así que sirve en CI.
Lo que este informe NO puede decir. Sin el payload no puedo afirmar si el CMS contiene webshells, a dónde va realmente el callback de licencia, ni qué hacen los binarios. Esas respuestas salen de tools/scan_payload.sh en cuanto tengas el .tar.gz.
